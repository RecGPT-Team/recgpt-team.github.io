# RecGPT Team

The organization homepage at https://recgpt-team.github.io/.

A static page with the team name, the existing RecGPT organization logo, and a link to UserArena Page. No build step or external dependencies.

The logo is the organization's existing public GitHub avatar, preserved in its original image format.

The title uses a self-hosted Montserrat ExtraBold subset from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/montserrat). Its license is included in `assets/fonts/OFL-Montserrat.txt`.
