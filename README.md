# RecGPT Team

The organization homepage at https://recgpt-team.github.io/.

A buildless static site preserving the original RecGPT logo, warm orange and cream palette, animated orbital hero, and Explore our work link, which scrolls directly to the research index. The UserArena project link sits alongside its paper in the preprints section.

Research is grouped into four technical reports, five accepted publications, and four preprints. All entries are static HTML in `index.html`; research styles are in `assets/research.css`. Full author lists use native accessible disclosures. RecMem has no paper link until its arXiv URL is supplied. Accepted publication venues follow the team-provided list. Preprints display arXiv and year only; do not display submission venues or review status.

The original logo and self-hosted Montserrat title font are unchanged. The font license is in `assets/fonts/OFL-Montserrat.txt` ([source](https://github.com/google/fonts/tree/main/ofl/montserrat)). Motion respects reduced-motion settings and can be paused.

Preview locally with `python3 -m http.server 4173 --bind 127.0.0.1`. GitHub Pages publishes `main` from the repository root. No external JavaScript, analytics, evaluation status feeds, or leaderboard data are loaded.
